# 域名墙，劫持，污染?
**<sapn class="marker-evy">墙是一个统称，他不够精确，劫持，污染可以都归类于墙。</sapn>**

**正常中的域名突然无法访问，一般有多种原因造成**

比如nginx解析错误，域名过期，服务器错误等问题，但是在这里只记录网络层问题。

有如下网络问题导致无法访问域名：

1. DNS 污染
2. IP/TCP 阻断
3. SNI/TLS 阻断
4. HTTP 劫持
5. 链路/IP 层过滤
6. 等等


| 如果把访问网站想象成寄快递：


> 用户输入域名（假设本地没有dns缓存） → 域名根服务器（他不存具体 IP，会转交给权威名称服务器）-> 查地址（DNS）→ 找到服务器（IP）→ 快递送到服务器（网络连接）→ 收到网页内容


## 1.网站被墙

::: details 点我查看
当你访问 google.com 时，浏览器会先向 DNS 服务器查询 google.com 的 IP 地址，然后再向该 IP 地址发送请求，最终返回网页内容。

在大陆你是无法访问的，因为 google.com 被墙了。

这就是所谓的“被墙”。被墙是指网站被中国大陆的防火长城（GFW）屏蔽，导致用户请求无法发送服务器，被中间网络（防火墙阻断）。

`GFW屏蔽是多重技术组合屏蔽`

DNS 污染作为第一道防线

IP 封锁作为第二道防线

TCP Reset 和 SNI/TLS 检测作为更深层的检测手段

结果就是：

* 一直转圈
* 超时
* ERR_CONNECTION_RESET
* Connection Reset

**<sapn class="marker-evy">`墙`是一个现象，至于为什么打不开，可能有很多原因：</sapn>**

* DNS 污染
* IP 封锁
* TCP Reset
* SNI 阻断
* TLS 阻断

**所以结论是**

`网站被墙 ≠ 域名污染`

域名污染只是导致网站被墙的一种方式。
:::

## 2.域名污染（DNS 污染）

::: details 点我查看
当你访问 google.com 时，浏览器会先向 DNS 服务器查询 google.com 的 IP 地址，然后再向该 IP 地址发送请求

比如谷歌服务器地址是 1.2.3.4 但是域名被污染，DNS 服务器返回了错误的 IP 地址，比如 4.6.7.8，甚至不存在的地址，导致浏览器无法访问。

**所以**

* 网站服务器其实正常
* 但是你被告诉了一个假的 IP

所以这就是 `域名污染`

:::

## 3.域名劫持

::: details 点我查看
**这个词容易和 DNS 污染混淆**

域名劫持是指攻击者通过篡改域名解析记录，将用户访问的域名指向攻击者控制的服务器，从而实现对用户的欺骗或攻击。

| 用户访问 A 网站，结果被人为改到了 B 网站。

**<sapn class="marker-evy">它可能发生在很多地方：</sapn>**

* DNS 劫持

| 访问 A 网站，DNS 服务器返回了 B 网站的 IP 地址

* 运营商劫持

| 访问 A 网站，运营商直接改了你的请求，返回了 B 网站的内容，或者302跳转到B网站，以前很多宽带都干过这事儿

* 路由器劫持

| 整个房间都会跳转走B网站

* 本地劫持

| 本地 Hosts 被修改

:::

## 三者总结

|  名称  |      发生位置       |     表现     |
 |:----:|:---------------:|:----------:|
| 网站被墙 |    网络传输层（统称）    |    无法访问    | 
| 域名污染 |     DNS 解析      | 域名解析到错误 IP | 
| 域名劫持 | DNS、运营商、路由器、本地等 | 跳到错误网站或广告页 | 

**一句话总结：**

**网站被墙**：访问路径被阻断，是一种最终现象。

**域名污染**：DNS 返回了错误结果，是导致网站无法访问的一种技术手段。

**域名被劫持**：访问请求被改道到其他地址，可能通过 DNS、运营商、路由器或本地配置等多种方式实现，不一定导致无法访问，但会让你访问到错误的目标。


## 检查是否被墙


找几个不同国家的机器，或者vpn测试，是否只有大陆无法访问

````[shell]
curl -I https://example.com

或者

ping example.com

如果海外机房能够访问，大陆无法访问，那么就可以判断是被墙了，接下来查具体原因

````
